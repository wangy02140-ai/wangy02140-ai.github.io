# Yao Wang — Academic Portfolio

Personal academic website presenting research in industrial design, human factors and ergonomics, cabin environments, and human–machine–environment system design.

Website: https://wangy02140-ai.github.io/

## Files

- `index.html`: biography, research, projects, education and engagement
- `script.js`: publication records and page interactions
- `styles.css`: responsive layout and visual design
- `portrait.png`: profile portrait
- `favicon.svg`: browser icon
- `.nojekyll`: serve the static files without Jekyll processing

No build step or package installation is required. GitHub Pages serves the root of the `main` branch.

## Updating

Edit biography and project text in `index.html`. Update publication records in `script.js`. Keep publication and degree statuses accurate; do not include under-review manuscripts in published-paper totals.
